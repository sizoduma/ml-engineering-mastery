# Module 5: Databricks Ecosystem

## Goal
Master the Databricks environment and understand how production ML work happens in a lakehouse platform.

## Learning outcomes

- navigate Databricks workspace and notebooks
- use Delta Lake and Spark effectively
- orchestrate workflows
- integrate MLflow and model serving
- understand how Mosaic AI and AI apps fit in

## Topics

### Databricks fundamentals
- clusters and jobs
- notebooks and reusable code
- secrets and workspace configuration
- job orchestration basics

### Data engineering in Databricks
- Delta Lake concepts
- table versioning and optimization
- reading and writing data at scale
- using SQL in Databricks
- ingestion and transformation patterns

### ML in Databricks
- model training with Python and Spark
- MLflow tracking and model registry
- model governance and lineage
- serving models via Databricks endpoints or integrations

### AI app and GenAI patterns
- Mosaic AI concepts
- AI applications and agent patterns
- vector search and RAG integration
- prompt-driven workflows

## Exercises

- Create and run a Delta Lake-based workflow
- Track and register a model using MLflow in Databricks
- Deploy a test model endpoint
- Build a small notebook-driven data pipeline and explain its stages

## Deliverable

Produce a Databricks project with:

- raw-to-curated transformation flow
- model training job
- MLflow tracking and registry setup
- documentation for how the pipeline would deploy to production
