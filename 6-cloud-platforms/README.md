# Module 6: Cloud Platforms and Azure for ML

## Goal
Build practical cloud skills for deploying ML systems in enterprise environments.

## Learning outcomes

- understand Azure architecture for ML workloads
- use Azure services relevant to ML engineering
- deploy containers and services in Azure
- operate orchestrated workloads on AKS
- align engineering work with cloud security and governance

## Topics

### Azure basics
- resource groups and subscriptions
- networking and identity basics
- storage services
- Azure monitoring and logging

### Azure ML and AI services
- Azure Machine Learning overview
- managed compute and endpoints
- deployment patterns
- security and environment configuration

### Kubernetes on Azure
- AKS architecture
- node pools and scaling
- ingress and networking
- secrets and configuration
- operational monitoring

### Cloud-native deployment patterns
- containers in Azure
- managed services vs self-managed services
- cost-aware deployment choices
- baseline resilience and scalability

## Exercises

- Create an Azure environment diagram for a model serving solution
- Deploy a containerized app to Azure Container Registry and AKS
- Configure environment variables and secrets in a managed environment
- Compare Azure-native ML deployment vs custom Kubernetes deployment

## Deliverable

Write a cloud deployment guide for a sample ML service with:

- architecture diagram description
- deployment steps
- security considerations
- cost and scaling notes
