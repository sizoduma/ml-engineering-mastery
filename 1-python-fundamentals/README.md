# Module 1: Python Fundamentals for ML Engineering

## Goal
Build strong Python fundamentals necessary for data work, machine learning engineering, experimentation, and production code.

## Core learning outcomes

By the end of this module you should be able to:

- write clear Python scripts and functions
- work with data structures and comprehensions
- use classes and modules effectively
- write tests for code quality and correctness
- debug and profile code
- understand packaging and environment management

## Topics

### 1. Python foundations
- syntax and variables
- control flow
- functions and scope
- lambda functions
- list, dict, set, tuple operations

### 2. Intermediate Python
- comprehensions
- iterators and generators
- file I/O
- exception handling
- context managers
- dataclasses

### 3. Object-oriented programming
- classes and inheritance
- composition over inheritance
- encapsulation and abstraction
- design decisions for maintainable code

### 4. Modules and packaging
- packages and imports
- virtual environments
- requirements files
- pyproject and packaging basics

### 5. Testing and quality
- pytest basics
- fixtures and parametrization
- unit tests vs integration tests
- mocking and isolation
- code style and linting

### 6. Practical engineering habits
- logging
- debugging tools
- profiling and performance basics
- documentation with docstrings

## Exercises

- Build a script that processes CSV data and summarizes metrics
- Write a reusable package for feature transformation logic
- Create pytest tests for a machine learning helper module
- Build a small CLI tool using argparse

## Suggested learning resources

- Python official docs
- Real Python tutorials
- Automate the Boring Stuff with Python

## Deliverable

Create a small Python project with:

- package structure
- tests
- README
- reusable functions
- sample data processing script
