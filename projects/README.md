# Projects

This folder is where your hands-on work goes.

## Recommended project flow

1. Start with a small data project in Module 1 or 2.
2. Build a basic ML pipeline in Module 3.
3. Add MLOps tracking in Module 4.
4. Rebuild the project in Databricks in Module 5.
5. Package the service in Docker and deploy to Kubernetes in Modules 6 and 7.
6. Create a GenAI or RAG project in Module 8.
7. Turn the model into a reusable API in Module 9.
8. Add CI/CD and operational monitoring in Module 10.
9. Finish with a platform-style architecture plan in Module 11.

## Suggested capstone project

Build an end-to-end ML product that includes:

- data ingestion
- cleaning and transformation
- model training and validation
- experiment tracking
- deployment to an API or serving endpoint
- monitoring and drift checks
- a small dashboard or operational summary

This capstone should simulate a real production ML application.
