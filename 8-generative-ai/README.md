# Module 8: Generative AI, LLMs, RAG, and AI Agents

## Goal
Develop the practical skills needed to work with modern LLM-powered applications.

## Learning outcomes

- understand transformer-based models and prompt design
- build RAG systems
- integrate external tools and knowledge retrieval
- evaluate AI application quality and safety
- design agent workflows with guardrails

## Topics

### LLM foundations
- tokens, context windows, embeddings
- prompting basics
- temperature and decoding parameters
- model selection tradeoffs

### Retrieval-Augmented Generation
- vector stores and embeddings
- chunking strategies
- semantic search
- document retrieval and grounding
- evaluation of retrieved context

### AI agents
- tool use and orchestration
- planning vs direct execution
- memory and workflow design
- safe and bounded agent patterns

### Production concerns
- latency and cost
- hallucination control
- prompt and retrieval evaluation
- content safety and moderation
- observability and tracing

## Exercises

- Create a simple RAG pipeline using a local or hosted model
- Compare prompt strategies for a business scenario
- Build a small tool-using agent with structured outputs
- Add an evaluation rubric for quality and hallucination checks

## Deliverable

Create a GenAI project with:

- a retrieval layer
- an LLM wrapper
- prompt template strategy
- evaluation approach
- deployment notes for production use
