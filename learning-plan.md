# Learning plan

## Phase 1: Foundations

- Python programming
- SQL and data processing
- statistics and ML fundamentals

## Phase 2: Production engineering

- MLOps
- Databricks
- cloud deployment
- Docker and Kubernetes

## Phase 3: AI product development

- LLMs and GenAI
- RAG and agents
- APIs and microservices

## Phase 4: Operational maturity

- DevOps
- monitoring
- governance
- platform-level design decisions

## Suggested milestone schedule

- Weeks 1-3: Python, SQL, and data work
- Weeks 4-6: ML fundamentals and model evaluation
- Weeks 7-9: MLOps and Databricks
- Weeks 10-12: Azure, Docker, and Kubernetes
- Weeks 13-15: GenAI, RAG, agent systems, and APIs
- Weeks 16-18: DevOps, monitoring, and advanced topics

## Success criteria

You are ready for this role when you can:

- explain and implement ML pipelines end to end
- deploy assets to cloud and container environments
- operate systems with monitoring and governance
- design and ship model-backed services
- work with LLM-based applications and retrieval systems
- communicate clearly with data science and platform teams
