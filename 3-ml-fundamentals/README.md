# Module 3: Machine Learning Fundamentals

## Goal
Understand the theory and practice behind machine learning models, evaluation, and deployment readiness.

## Learning outcomes

- explain common ML algorithms and when to use them
- perform feature engineering and validation
- evaluate model quality with correct metrics
- tune model hyperparameters responsibly
- prepare a model for production

## Topics

### Core ML concepts
- supervised vs unsupervised learning
- classification vs regression
- train/validation/test splits
- cross-validation
- underfitting and overfitting
- bias-variance tradeoff

### Feature engineering
- imputation
- encoding
- scaling
- interaction terms
- handling missing data
- leakage prevention

### Model families
- linear models
- logistic regression
- decision trees and random forests
- gradient boosting
- support vector machines
- clustering basics

### Evaluation
- accuracy, precision, recall, F1, ROC-AUC
- MAE, MSE, RMSE, R2
- confusion matrices
- calibration and threshold selection
- business metric alignment

### Experimentation
- hyperparameter search
- feature importance
- reproducibility and tracking
- evaluation pipelines

## Exercises

- Train a model on a tabular dataset and compare algorithms
- Run cross-validation and choose a model with justification
- Build a feature engineering pipeline with train/test separation
- Evaluate model performance using appropriate metrics for class imbalance

## Deliverable

Produce a machine learning notebook or project that:

- defines a clear business problem
- trains at least two candidate models
- compares them using validation metrics
- explains the final choice
- demonstrates clean, reproducible logic
