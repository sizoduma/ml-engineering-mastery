# Module 10: DevOps and Production Engineering

## Goal
Strengthen the engineering practices required to build, deploy, and maintain ML systems reliably.

## Learning outcomes

- use Git and GitHub workflows effectively
- implement CI/CD pipelines
- automate infrastructure and deployment
- monitor health and performance
- create operational runbooks and incident response habits

## Topics

### Version control and collaboration
- commit hygiene
- code reviews
- branch strategies
- pull requests and merge discipline

### CI/CD
- linting and tests
- build pipelines
- approval gates
- environment promotion
- deployment automation

### Infrastructure as Code
- Terraform basics
- environment provisioning
- service configuration management
- secrets and policy controls

### Monitoring and reliability
- logs and metrics
- observability suites
- alerts and incident playbooks
- service health checks

## Exercises

- Create a GitHub Actions pipeline for a Python project
- Add linting, tests, and package checks
- Use Terraform or another IaC tool for a minimal deployment
- Write a simple runbook for diagnosing a failing inference service

## Deliverable

Create a devops setup for a sample ML project with:

- CI pipeline
- deployment automation
- monitoring notes
- incident response checklist
